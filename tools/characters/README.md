# 반달이 · 꼬미 스프라이트 파이프라인

오피스의 직원 캐릭터(반달이, 꼬미)는 **국립공원공단 캐릭터 규정집(Character
Standards) PDF의 턴어라운드 벡터 원화**(CS06 반달이 / CS07 꼬미: 정면·후면·측면)를
그대로 잘라 리깅해서 만든 스프라이트 시트입니다. 원화를 다시 그리거나 색을 바꾸지 않고,
부위별 레이어를 움직여 프레임을 만듭니다(추가로 그린 것은 감은 눈 곡선과, 들어 올린
팔의 둥근 실루엣뿐입니다).

```
PDF ──extract.cjs──▶ source/*.svg ──rig.js + build.cjs──▶ assets/characters/<id>/sheet.png
                    (뷰별 벡터)        (리깅·렌더)            + manifest.json
```

## 다시 만들기

```bash
# 1) PDF에서 뷰별 SVG 추출 (poppler-utils의 pdftocairo 필요)
node tools/characters/extract.cjs "2. Character Standards.pdf"

# 2) 스프라이트 시트 렌더 (Playwright Chromium 필요)
npm run build:characters

# 3) 미리보기: 저장소 루트를 HTTP로 띄우고 열기
npx http-server . -p 4600   # → http://127.0.0.1:4600/tools/characters/preview.html
```

`source/*.svg`는 이미 커밋되어 있으므로 PDF 없이도 2)부터 다시 실행할 수 있습니다.

## 리그가 하는 일 (`rig.js`)

| 부분 | 방법 |
|---|---|
| 다리 (정면/후면) | 실루엣을 엉덩이 선 아래에서 좌·우로 잘라 번갈아 들어 올림 |
| 다리 (측면) | 엉덩이 선 기준 전단(shear) 변형으로 앞뒤로 내딛기, 먼 쪽 다리는 살짝 어둡게 |
| 팔 (측면 걷기) | 팔 윤곽선 루프 영역을 어깨 피벗으로 회전 |
| 팔 (손 흔들기·타이핑·컵 들기) | 원래 팔 영역을 몸통에서 빼고, 캐릭터 비율의 둥근 팔을 회전해 그림. 몸통과 겹치는 부분에만 원화와 같은 색의 윤곽선 |
| 3/4 방향 (↘↙↗↖) | 외곽선은 그대로 두고 눈·주둥이·가슴 무늬·모자 배지·귀·꼬리를 원통 위에서 회전한 위치로 이동(가장자리로 갈수록 가로로 압축) |
| 좌측(←) | 공식 측면도와 동일하게 우측(→)을 좌우 반전 |
| 눈 깜빡임·낮잠 | 눈 도형을 숨기고 같은 위치에 감은 눈 곡선 |

## 애니메이션과 방향

| 애니메이션 | 프레임 | 방향 | 오피스에서 쓰이는 곳 |
|---|---|---|---|
| walk | 8 | 8방향 | 이동 (걸은 거리로 프레임 진행 → 발 미끄러짐 없음) |
| idle | 6 | 8방향 | 서 있기, 숨쉬기 + 눈 깜빡임 |
| sit | 4 | 6방향 | 책상에서 생각 중, 소파·의자 |
| type | 4 | ↙ ↗ ↓ ↑ | 도구 실행·답변 작성 중 |
| wave | 6 | ↙ ↗ ↓ ↑ | 사용자 응답 대기 / 오류 |
| nap | 4 | ↙ ↗ ↓ ↑ | 빈 책상에서 졸기 |
| hold | 4 | ↓ ↑ | 커피·물·전화·책·탁구채 |
| reach | 4 | ↑ ↓ | 화이트보드·오락기·자판기 |

책상은 격자 축 방향이라 화면에서는 대각선(↙ 앞쪽, ↗ 뒤쪽)을 봅니다. 그려지지 않은
방향은 런타임(`public/characters.js`)이 가장 가까운 방향으로 대체합니다.

## 배역 바꾸기

`assets/characters/index.json`의 `cast`에서 정합니다. 기본값: Claude 세션은 반달이,
Codex 세션은 꼬미, 서브에이전트는 꼬미, 나머지 에이전트는 세션별로 섞어서. 화면 크기는
`height`(2D 오피스 기준 px), 걸음 길이는 `stride`(한 걸음 주기당 타일 수)입니다.
설정 메뉴의 **반달이·꼬미 직원** 스위치로 기본 사람 캐릭터로 되돌릴 수 있습니다.
